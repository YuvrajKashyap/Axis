# AXIS PROJECT RULES

Axis is a personal alignment and reset tool.

Core loop:
Open -> Reset -> Act

## Product rules
- Anti-algorithm
- Minimal, premium, cinematic
- No generic SaaS dashboard patterns
- No unnecessary features
- Prefer real data over placeholders
- Keep the experience sharp, calm, and intentional

## Engineering rules
- Do not touch 3D unless explicitly asked
- Preserve working routes and database behavior
- Prefer simple, grounded implementations
- Explain planned file edits before making them
- Avoid fake backend logic
- Keep changes small and safe

## UI rules
- No purple-gradient AI slop
- No fake analytics widgets
- No sidebars unless explicitly needed
- Prioritize spacing, hierarchy, and typography
- Desktop-first, responsive
